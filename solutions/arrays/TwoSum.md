# 1. Two Sum

**Difficulty:** Easy

Store previously seen numbers and their indices in a hash map. For each number, check whether the required complement was seen earlier. Return the pair of distinct indices when found.

- Time: O(n) average
- Auxiliary space: O(n)
- Edge cases: duplicate values (e.g., [3,3], target 6), negative numbers, zero.
